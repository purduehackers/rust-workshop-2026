# Challenge problems

Small exercises in the style of [Rust By Practice](https://practice-rust.beatai.org/)
by sunface and contributors, which is where the format comes from and
where several of these problems are adapted from. The rest were written
for this workshop, with help from AI, and follow the same format. Each
file is one exercise. Make it compile and run without panicking, and it
prints `Success!`.

```sh
cd 03-ownership
cargo run --bin 2
```

Chapters 01 to 08 cover what the workshop covered. Chapters 09 to 14 each
add one small idea, explained in a comment at the top of the first exercise.
